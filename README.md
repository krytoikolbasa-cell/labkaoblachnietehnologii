# Neon Space Defender

Учебный веб-проект в рамках дисциплины **«Основы облачных технологий»**.
**Neon Space Defender** — динамичный космический 2D-шутер, реализованный в виде легковесного
статического веб-приложения (SPA) на базе HTML5 Canvas, JavaScript и Web Audio API.

## Архитектура
| Компонент | Назначение | Связь с другими компонентами |
| :--- | :--- | :--- |
| **UI / HUD слой** | Отображает меню, шкалы здоровья/щита и счёт | Обновляется из игрового цикла через DOM API |
| **Игровой движок** | Физика, волны врагов, коллизии, рендер | Управляет сущностями и вызывает звуковой модуль |
| **Звуковой синтезатор** | Генерация звуков через Web Audio API | Вызывается при выстрелах, взрывах и бонусах |
| **Клиентское хранилище** | Сохранение рекорда в `localStorage` | Читается при старте и обновляется при рекорде |
| **Облачный хостинг / CDN** | Доставка HTML и библиотек Tailwind/Fonts | Передаёт статические ресурсы по HTTPS |

## Структура репозитория
- `Neon Space Defender Game.html` — основной файл приложения (разметка, стили и логика)
- `README.md` — техническая документация проекта

## Инструкция по запуску
1. Клонировать репозиторий: `git clone https://github.com/krytoikolbasa-cell/labkaoblachnietehnologii.git`
2. Перейти в папку: `cd labkaoblachnietehnologii`
3. Открыть `Neon Space Defender Game.html` в браузере или запустить локальный сервер: `python -m http.server 8000`
4. Для облачного деплоя включить GitHub Pages в настройках репозитория (ветка `main`, корень `/`).
